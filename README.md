# AI-Agents

Проект содержит трёх AI-помощников-собеседников.

- **Леонид** — безопасник по ИБ
- **Оптимус** — специалист по защите галактики
- **Риддик** — даёт нужные советы

## Требования

- Go 1.25+
- Python 3.11
- RTX-GPU с CUDA (для озвучки голосом) — опционально

## Запуск

```
run.bat
```

Сервер поднимется на `http://localhost:8098`.

## Функции

- Три персонажа с уникальными голосами (XTTS v2, клонирование)
- Переключение персонажа кнопками в сайдбаре или по ключевым словам: "Леонид", "Оптимус", "Риддик"
- Голосовой ввод (кнопка микрофон), отправка после паузы 3 сек
- История диалога в SQLite
- Геолокация: персонажи знают местоположение, ближайшие объекты (OpenStreetMap)
